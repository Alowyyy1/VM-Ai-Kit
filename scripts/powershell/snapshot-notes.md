# Инструкция по созданию снапшотов (Snapshot Workflow)

Перед запуском любых подозрительных бинарников, читов или малвари в виртуальной машине:

1. **Базовый снапшот ("Clean Baseline"):**
   - Установите Windows в виртуальную машину (VMware / VirtualBox).
   - Запустите `install-vm.ps1` для развертывания AgentKit, Python, x64dbg и утилит.
   - Запустите `defender-exclusions.ps1`, чтобы Защитник Windows не удалял реверсерские утилиты.
   - Убедитесь, что служба агента запущена и отвечает на хосте (`/healthz`).
   - Выключите виртуальную машину (или сделайте снапшот в работающем состоянии).
   - Назовите снапшот: `AgentKit-Clean-Ready`.

2. **Работа с семплами:**
   - Копируйте исследуемые файлы (например, `localHero.dll`, `LoaderKernel.dll`) в `C:\Analysis` или `C:\d2p191126`.
   - Проводите динамический анализ, трассировку, дамп памяти.

3. **Откат:**
   - По завершении анализа или в случае краша/заражения системы вернитесь к снапшоту `AgentKit-Clean-Ready` в один клик.
